# 量研 · 本地 A 股量化研究与手动交易参考（v0.4）

一个在本机运行的沪深主板量化研究、模拟交易和手动交易参考工具。它不连接券商、不自动下单、不承诺盈利；价格、股数和退出条件由明确规则计算，不使用语言模型猜价。

English summary: LiangYan is a local, manual-trading A-share research and paper-trading tool. It does not place orders or guarantee returns.

## 功能

- 全市场主板历史日线准备（BaoStock）与公开报价监测（新浪）。
- 稳健 / 激进两套独立模拟账户；固定风险上限；费用、滑点、T+1、涨跌停、停牌和 ST 过滤。
- 首页最多 5 个候选，显示买入区间、股数、止损、止盈和最长持有期限；午休、集合竞价、闭市和非交易日不模拟成交。
- 真实持仓账本：只记录用户已在券商完成的交易；现金核对；最近录入撤销；真实账户与模拟账户分离。
- 策略进化：历史训练 / 验证 / 独立测试，收益、回撤和双倍费用压力门槛；通过后才冻结候选，再做至少 20 个共同交易日、10 笔完整买卖的前瞻模拟观察。没有候选通过时保留原版，不为了“看起来在进步”而放松门槛。
- 数据与设置：准备进度、失败重试、桌面提醒、数据库备份。

## 从源码运行

- Windows 10/11 x64，Python 3.12。
- `pip install -r requirements.txt`
- PowerShell 设置数据目录（默认 `D:\量化数据`）：
  ```powershell
  $env:QUANT_DATA_HOME = 'D:\量化数据'
  ```
- 启动：
  ```powershell
  python src/main.py
  ```
- 打开 `http://127.0.0.1:8765/`，点击“开始工作”。
- 历史准备和报价需要正常网络；行情、账本和研究结果只保存在本机数据目录。
- 关闭界面后后台继续运行；点“停止工作”只暂停，断点保留。
- 本仓库是源码版。`packaging/` 是 Windows 独立窗口/安装包的构建代码，构建脚本中的本机工具路径需要按你的环境修改。

## 数据与隐私

- 本仓库不包含作者的真实账户、持仓、成交、行情数据库或本机运行日志。
- 首次运行会在数据目录创建空白的模拟账户；真实账户默认为空。若你要导入自己的起始持仓，请自行创建 `config/opening-account.json`，不要提交到版本库。
- 所有数据保存在本机；软件不上传账户数据。
- 为保护账户隐私，仓库不附带依赖作者真实账户的本地测试夹具。作者本机的完整回归为 174 项；本仓库包含不依赖私人账户的那部分测试。

## 风险与边界

- 仅用于学习和研究，不构成投资建议；不保证收益、不保证长期无故障。
- 公开数据源可能延迟、缺失或中断；历史检验使用日线，不能精确复现盘中每一笔报价和成交。
- 现金分红按 20% 预留税、零碎送股向下取整是保守处理，不是完整持有期限税制；无法解释的除权、未到账/未上市权益、配股和退市清算会阻止晋升。
- 实盘参考需要用户手动启用；券商交易始终由用户本人执行。
- 软件不会因为“策略进化”自动变得更赚钱；大多数历史候选会被门槛淘汰，这是设计的一部分。

## 测试

仓库包含不依赖私人账户的测试。默认使用 `D:\量化数据\work` 作为临时目录；如果你的机器没有 D:，请修改测试中的路径或先创建该目录。

```powershell
python -m unittest discover -s tests -v
```
